# Dependency records

This directory contains versioned admission records required by the
[dependency and license policy](../engineering/dependency-and-license-policy.md).
An admission approves only the stated direct selection and constraints. It does
not approve an unresolved lock graph, an installation, or a release.

- [M1 foundation admission](m1-foundation-admission.md): FND-I00 exact direct
  runtime and tool selection for the V1-M1 foundation wave.
- [M1 foundation lock review](m1-foundation-lock-review.md): FND-I01 development
  toolchains, reproducible commands, reviewed graph and deferred release risks.
