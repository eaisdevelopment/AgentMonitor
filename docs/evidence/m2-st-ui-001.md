## Security, compatibility, and integrity

No new package was added by P02; existing React/TypeScript/Playwright/Chrome toolchain is used. No backend, OpenAPI, generated client, persistence schema, provider profile, or account credential was edited by P02. The production UI contains no direct `fetch` outside the generated client, no browser-storage credential cache, no simulated metrics, and no external network request in the tested workflows. One-time token plaintext is held only in the immediate modal, destroyed on close/navigation/reload, and never written to logs or screenshots. Copy is a user gesture. Module guidance is in [`react-dashboard.md`](../modules/react-dashboard.md).

All evidence is sanitized: commands and stage/status outputs only; no password, bearer, CSRF, cookie, account identifier, token prefix, provider content, prompt, response, source, or raw process environment value is retained here. The only test-created API tokens exist in temporary file databases. No mocks, fakes, stubs, emulator, response recording/replay, seeded telemetry, placeholder dashboard values, disabled assertion, test-only production branch, or swallowed test failure is used.
