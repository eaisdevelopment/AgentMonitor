## Delivered M01 behavior and test inventory

The application ports cover password login, session resolution, CSRF decision, logout, bounded browser-only session list, target/bulk revocation, current-password change, and explicit authorization. Every browser-session port requires a bounded caller request correlation ID; observed-expiry audit reuses it unchanged. The production repository uses real Argon2id, OS randomness, actual owner-only file-backed SQLite after the real `v1_0100` Alembic migration, and real UTC wall time. Tests bootstrap their isolated administrator through `BootstrapAdministratorV1`; they never insert a test administrator or substitute a repository/hasher/clock. Session/CSRF issue values are redacted and nonserializable. Real rows contain only selectors/digests, bounded lifecycle metadata, and safe audit facts. Browser mutation ports recheck the actor session and CSRF in their own transaction. Login and current-password verification share a durable installation-global throttle. Password change revokes old sessions, leaves API tokens untouched, and issues one new one-time session/CSRF pair. An authenticated replay with its idempotency key cannot replay a secret.
